## 一、灵活就业社保补贴（就业困难人员）

### 1.1 政策依据

- **核心文件**: 《甘肃省就业补助资金管理办法》(甘财社〔2024〕152号)
- **配套文件**: 《关于进一步做好就业困难人员认定及经办服务等工作的通知》(甘人社通〔2024〕204号)

### 1.2 适用对象

法定劳动年龄内，满足以下**全部条件**的就业困难人员：

1. 经公共就业服务机构**认定为就业困难人员**（需持有《就业创业证》）
2. 以非全日制、临时性、弹性工作等灵活形式就业并**取得合法劳动报酬**
3. 在公共就业服务机构进行**灵活就业登记**
4. 以灵活就业人员身份**缴纳社会保险费**

**就业困难人员认定标准**（7类）：

| 类别 | 具体说明 |
|------|----------|
| 城镇大龄人员 | 距离领取养老保险待遇不足10年的城镇常住人口 |
| 零就业家庭成员 | 同一户籍家庭中有劳动能力成员均处于失业状态 |
| 城镇低保人员 | 享受城镇最低生活保障待遇的人员 |
| 残疾人 | 持有《残疾人证》或《残疾军人证》的城镇常住人口 |
| 长期失业人员 | 连续失业6个月以上（含毕业6个月后未就业的高校毕业生） |
| 失地农民 | 被县级及以上政府统一征地后完全失去承包土地的农民 |
| 其他 | 省政府规定的其他就业困难人员 |

### 1.3 申请条件（不予申报情形）

有下列情形之一的**不予申报**：

1. 已与用人单位建立劳动关系或在用人单位参加社会保险的
2. 从事个体经营、创办企业并已领取营业执照的
3. 担任法定代表人、股东（合伙人）、监事、理事或负责人职务的
4. 正在享受创业担保贷款的
5. 丧失劳动能力的
6. 正在享受失业保险待遇或其它社会保险补贴待遇的
7. 因个人缴费年限不足而延迟退休的
8. 享受灵活就业人员社保补贴已达到规定期限的

### 1.4 补贴标准 ★计算口径

| 计算要素 | 口径说明 |
|----------|----------|
| **补贴比例** | 按不超过个人**实际缴费额的2/3**给予补贴 |
| **缴费基数限制** | 对超过社保缴费基数**100%**部分不予补贴 |
| **补贴方式** | 先缴后补 |
| **不足一年** | 按实际缴费月数计算 |

**具体金额示例（灵台县2025年标准）**：

```
2025年城镇职工基本养老保险最低年缴费额 = 10,567.20元
补贴金额 = 10,567.20 × 2/3 ≈ 7,045元/年
月补贴 = 7,045 ÷ 12 ≈ 587元/月
```

> ⚠️ **注意**：具体金额因各地最低缴费基数不同而有差异，但**计算比例（2/3）全省统一**。

### 1.5 补贴期限

| 补贴对象 | 补贴期限 |
|----------|----------|
| 一般就业困难人员 | 最长不超过**3年**（36个月） |
| 距法定退休年龄不足5年的就业困难人员 | 可延长至**退休** |
| 计算起点 | 以初次核定其享受社会保险补贴时年龄为准 |

### 1.6 申请材料

| 序号 | 材料名称 | 备注 |
|------|----------|------|
| 1 | 身份证 | 原件及复印件 |
| 2 | 社会保障卡 | 原件及复印件（需激活金融功能） |
| 3 | 《就业创业证》（或《就业失业登记证》） | 原件及复印件 |
| 4 | 《就业困难人员认定申请表》 | 初次申请需提供 |
| 5 | 当年度城镇职工基本养老保险缴费凭证 | 原件及复印件 |
| 6 | 灵活就业人员社会保险补贴申报表 | 各地自有模板 |

### 1.7 办理流程

```
第1步：就业困难人员认定
  │   向户籍地社区/乡镇公共就业服务机构申请
  │   → 初审公示（5个工作日）→ 复核认定（5个工作日）
  ▼
第2步：灵活就业登记
  │   在甘肃人社综合服务平台进行登记
  ▼
第3步：缴纳社会保险费
  │   以灵活就业人员身份按时足额缴纳
  ▼
第4步：提交补贴申请
  │   向户籍地社区提交申请材料
  ▼
第5步：社区初审 → 县人社局复核
  ▼
第6步：公示（不少于3个工作日）
  ▼
第7步：资金拨付到个人社保卡账户
```

## 二、高校毕业生灵活就业社保补贴

### 2.1 政策依据

- **核心文件**: 《甘肃省就业补助资金管理办法》(甘财社〔2024〕152号)

### 2.2 适用对象

满足以下**全部条件**的高校毕业生：

1. **离校2年内**未就业的高校毕业生（如2025年申报：2024年和2025年毕业）
2. 在公共就业服务机构进行**灵活就业登记**
3. 以灵活就业人员身份**缴纳社会保险费**

### 2.3 申请条件（不予申报情形）

与就业困难人员灵活就业社保补贴的排除条件基本一致， additionally：

- 达到法定退休年龄的
- 已注册营业执照的个体工商户或企业法定代表人
- 完全丧失劳动能力的
- 未按规定及时足额缴纳养老保险费的
- 正在享受失业保险待遇或其它社会保险补贴待遇的

### 2.4 补贴标准 ★计算口径

| 计算要素 | 口径说明 |
|----------|----------|
| **补贴比例** | 按不超过个人**实际缴费额的2/3**给予补贴 |
| **缴费基数限制** | 对超过社保缴费基数**100%**部分不予补贴 |
| **补贴方式** | 先缴后补 |
| **不足一年** | 按实际缴费月数计算 |

> **与就业困难人员的区别**：计算比例相同（均为2/3），但**补贴期限不同**。

### 2.5 补贴期限

| 补贴对象 | 补贴期限 |
|----------|----------|
| 离校2年内高校毕业生 | 最长不超过**24个月**（2年） |

> ⚠️ 对比：就业困难人员最长36个月，高校毕业生最长24个月。

### 2.6 申请材料

| 序号 | 材料名称 | 备注 |
|------|----------|------|
| 1 | 身份证 | 原件及复印件 |
| 2 | **毕业证书** | 原件及复印件（关键材料） |
| 3 | 社会保障卡 | 原件及复印件 |
| 4 | 《就业创业证》 | 原件及复印件 |
| 5 | 当年度社会保险缴费凭证 | 原件及复印件 |
| 6 | 灵活就业证明材料 | 社区出具 |
| 7 | 个人材料真实性承诺书 | 签字确认 |
| 8 | 高校毕业生灵活就业社保补贴申请表 | 各地自有模板 |

### 2.7 办理流程

与就业困难人员流程基本一致，但**无需进行就业困难人员认定**：

```
第1步：灵活就业登记（在公共就业服务平台）
  ▼
第2步：缴纳社会保险费
  ▼
第3步：提交补贴申请（社区/乡镇）
  ▼
第4步：社区初审 → 县人社局复核
  ▼
第5步：公示
  ▼
第6步：资金拨付到个人社保卡账户
```

## 三、一次性创业补贴

### 3.1 政策依据

- **核心文件**: 《甘肃省就业补助资金管理办法》(甘财社〔2024〕152号)

### 3.2 适用对象

满足以下**全部条件**的人员：

1. **首次创办**小微企业或从事个体经营
2. 所创办企业或个体工商户自工商登记注册之日起**正常运营1年以上**
3. **当前仍在正常经营**
4. 属于以下四类人员之一：
   - 就业困难人员
   - 离校2年内高校毕业生
   - 返乡入乡创业人员
   - 就业困难退役军人

### 3.3 补贴标准 ★计算口径

| 计算要素 | 口径说明 |
|----------|----------|
| **补贴金额** | **5,000元**（一次性） |
| **补贴性质** | 一次性发放，非按月/按年 |
| **发放方式** | 拨付到个人社会保障卡银行账户 |

### 3.4 补贴期限

| 补贴对象 | 补贴期限 |
|----------|----------|
| 符合条件的创业者 | **一次性**（每人仅可享受1次） |

### 3.5 申请材料

| 序号 | 材料名称 | 备注 |
|------|----------|------|
| 1 | 基本身份类证明 | 身份证复印件 |
| 2 | 营业执照正副本复印件 | 注册法人必须是本人 |
| 3 | 个人真实性承诺书 | 签字确认 |

### 3.6 办理流程

```
第1步：准备材料（身份证、营业执照、承诺书）
  ▼
第2步：向当地人社部门提交申请
  ▼
第3步：人社部门审核
  ▼
第4步：财政部门将补贴资金支付到社保卡银行账户
```

## 四、创业担保贷款

### 4.1 政策依据

- **核心文件**: 《甘肃省创业担保贷款实施办法》(甘人社通〔2024〕299号)
- **配套文件**: 《甘肃省普惠金融发展专项资金管理实施细则》(甘财金〔2024〕15号)

### 4.2 适用对象

#### 个人创业担保贷款（10类重点群体）

法定劳动年龄内（年满16周岁且贷款期内未达到依法享受基本养老保险待遇年龄），具有完全民事行为能力：

| 序号 | 人员类别 |
|------|----------|
| 1 | 城镇登记失业人员 |
| 2 | 就业困难人员（含残疾人） |
| 3 | 退役军人 |
| 4 | 刑满释放人员 |
| 5 | 高校毕业生（含大学生村官和留学回国学生） |
| 6 | 化解过剩产能企业职工和失业人员 |
| 7 | 返乡创业农民工 |
| 8 | 网络商户（连续经营12个月以上，月营业额≥3000元，好评率≥95%） |
| 9 | 脱贫人口 |
| 10 | 农村自主创业农民 |

#### 小微企业创业担保贷款

- 属于现行中小企业划型标准规定的小型、微型企业
- 申请前1年内新招用符合条件人数达到在职职工人数的**10%**（超100人企业为5%）
- 签订1年以上劳动合同
- 无拖欠工资、欠缴社保费等违法违规记录

### 4.3 申请条件

**个人申请条件**：
1. 属于上述10类重点群体
2. 已创办企业/个体工商户/民办非企业单位/农民专业合作社等，并在甘肃省内注册登记
3. 除助学贷款、脱贫人口小额信贷、住房贷款、购车贷款、5万元以下小额消费贷款外，**本人及配偶无其他贷款**

### 4.4 贷款额度与期限 ★计算口径

| 项目 | 个人 | 小微企业 |
|------|------|----------|
| **贷款额度** | 最高**30万元** | 最高**400万元** |
| **贷款期限** | 最长**3年** | 最长**2年** |
| **合伙创业额度** | 个人额度上限之和的**110%**，且不超过小微企业上限 | — |
| **展期** | 到期后可展期**1次**，不超过**1年**（展期不贴息） | 同左 |
| **循环次数** | 累计不超过**3次** | 累计不超过**3次** |

> **特殊政策**：兰州市高校毕业生在兰创业，最高可申请**50万元**个人创业担保贷款（超出30万元部分按实际利率50%贴息，资金从兰州市人才专项资金列支）。

### 4.5 贴息标准 ★计算口径

| 计算要素 | 口径说明 |
|----------|----------|
| **贴息比例** | 财政部门给予贷款实际利率的**50%**财政贴息 |
| **借款人承担** | 剩余**50%**由个人/企业承担 |
| **贷款利率上限** | 脱贫县区：LPR+250BPs；其他县区：LPR+150BPs |
| **2025年执行利率** | 年利率**3.4%**（部分县市3.6%） |
| **贴息方式** | 先付后贴（按季付息，财政贴息到账后银行3个工作日内划入借款人账户） |
| **展期/逾期** | **不予贴息** |

**实际成本计算示例**：

```
假设贷款30万元，年利率3.4%，期限3年：

年利息 = 300,000 × 3.4% = 10,200元
财政贴息 = 10,200 × 50% = 5,100元/年
个人承担 = 10,200 × 50% = 5,100元/年
3年个人总利息成本 = 5,100 × 3 = 15,300元
```

### 4.6 反担保要求

| 贷款额度 | 反担保要求 |
|----------|------------|
| **10万元以下** | **免反担保** |
| **10万-15万元** | 需1名反担保人 |
| **16万-30万元** | 需2名反担保人 |

**反担保方式**（可任选其一）：
1. **第三责任人担保**：行政机关、事业单位工作人员（距退休3年以上）
2. **抵押/质押**：房屋、汽车、机械设备、有价证券、知识产权等

**免反担保情形**：
- 10万元以下个人贷款
- 全国创业孵化示范基地或信用社区推荐的创业项目
- 获得市级以上荣誉称号的创业人员/项目
- 经金融机构评估认定的信用贷款发放对象
- 经营稳定守信的二次创业者
- "陇原人才服务卡"持卡人配偶

### 4.7 申请材料

**个人申请**：

| 序号 | 材料名称 |
|------|----------|
| 1 | 《个人申请创业担保贷款审核表》 |
| 2 | 身份证、户口本、社保卡、结婚证 |
| 3 | 营业执照正本（副本）原件 |
| 4 | 分类身份证明（《就业创业证》/退役证/毕业证书/返乡创业证明/网店经营证明等） |

**小微企业申请**：

| 序号 | 材料名称 |
|------|----------|
| 1 | 《创业担保贷款审核表（小微企业）》 |
| 2 | 法定代表人身份证、营业执照 |
| 3 | 企业章程 |
| 4 | 新招用人员劳动合同及身份认定材料 |
| 5 | 职工花名册 |
| 6 | 资产负债表、利润表 |

### 4.8 办理流程

```
第1步：提交申请
  │   向创业项目所在地社区/乡镇提交材料
  │   （部分地区可直接向县级人社部门提交）
  ▼
第2步：人社部门资格审核（7个工作日内）
  │   审核借款人资格，符合条件的推荐给担保机构
  ▼
第3步：担保机构尽职调查（3个工作日内）
  │   调查创业项目、信用状况、偿债能力等
  ▼
第4步：经办银行贷款审批发放（5个工作日内）
  │   签订担保合同和贷款合同 → 放款
  ▼
第5步：按季付息 → 财政贴息到账 → 银行划入账户
```

### 4.9 重要注意事项

1. **培训要求**：审核合格者须参加创业能力提升培训班，培训合格方可放款
2. **申请次数**：已累计享受过3次创业担保贷款的人员不得申请
3. **严禁申请人群**：企业在职/退休职工、公益性岗位人员、行政事业单位在职/退休职工、在校学生
4. **高校毕业生特殊规定**：未就业大学生获贷后通过考试就业上岗后6个月内必须归还贷款
5. **申请地限制**：在创业项目登记注册所在地申请

## 五、四项补贴计算口径汇总对比

### 5.1 核心计算口径一览表

| 补贴项目 | 补贴标准 | 补贴期限 | 补贴上限 | 发放方式 |
|----------|----------|----------|----------|----------|
| 灵活就业社保补贴（就业困难人员） | 实际缴费的**2/3** | 最长**36个月**（距退休不足5年可延至退休） | 超过缴费基数100%部分不予补贴 | 先缴后补，拨付社保卡 |
| 高校毕业生灵活就业社保补贴 | 实际缴费的**2/3** | 最长**24个月** | 超过缴费基数100%部分不予补贴 | 先缴后补，拨付社保卡 |
| 一次性创业补贴 | **5,000元** | 一次性（1次） | — | 一次性拨付社保卡 |

### 5.2 实际收益测算

#### 场景1：就业困难人员灵活就业社保补贴

```
假设：2025年甘肃省最低年缴费额 = 10,567.20元
补贴 = 10,567.20 × 2/3 ≈ 7,045元/年
3年总补贴 ≈ 7,045 × 3 = 21,135元
（如距退休不足5年，可享至退休，总补贴更高）
```

#### 场景2：高校毕业生灵活就业社保补贴

```
假设：同上最低缴费额 = 10,567.20元/年
补贴 = 10,567.20 × 2/3 ≈ 7,045元/年
2年总补贴 ≈ 7,045 × 2 = 14,090元
```

#### 场景3：一次性创业补贴

```
补贴 = 5,000元（一次性）
无需偿还
```

#### 场景4：创业担保贷款（个人30万元）

```
年利率 = 3.4%
年利息 = 10,200元

个人年利息成本 = 5,100元

```

### 5.3 政策叠加使用说明

## 七、关键提醒

1. **省级统一标准 + 县级具体执行**：补贴比例（2/3）、金额（5000元）、额度（30万/400万）等核心标准由省级文件统一规定，但具体申报时间、窗口、材料模板以各县区公告为准。

2. **先缴后补原则**：社保补贴均实行"先缴后补"，必须先自行缴费，再申请补贴。

3. **认定前置**：就业困难人员必须先完成认定，再进行灵活就业登记，最后才能申请补贴。顺序不能颠倒。

4. **互斥条款**：正在享受创业担保贷款的，不可同时享受灵活就业社保补贴。

5. **申报时效**：各县区每年集中申报一次，通常在9-11月，逾期不予补办。

6. **咨询渠道**：全国人社服务热线 **12333**，或各县区人社局电话。
