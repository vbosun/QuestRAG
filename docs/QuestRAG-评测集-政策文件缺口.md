# QuestRAG 评测集政策文件缺口

当前 ES 知识库已能支撑就业登记、失业登记、就业创业证、个人就业登记办事指南、个人创业担保贷款申请、部分就业困难人员补贴和岗位检索评测。

以下问题在现有知识库里证据不足，建议补充政策文件后再作为严格标准答案评测：

1. `12333是干什么的？`
   - 现有资料只证明 `12333.gov.cn`、`掌上12333`、微信小程序 `12333` 是失业登记线上办理入口。
   - 如要标准回答“12333 是人社服务热线或咨询服务电话”，需要补充 12333 咨询服务热线/全国人社服务平台介绍类官方材料。

2. `我毕业两年没工作，自己交社保能领补贴吗？`
   - 现有资料稳定支持“就业困难人员灵活就业并缴纳社保，可按不超过个人实际缴费 2/3 补贴”。
   - 缺少“离校 2 年内未就业高校毕业生灵活就业社会保险补贴”的对象、条件、期限、申请材料、办理渠道。

3. `办理了失业登记，会不会影响以后找工作？`
   - 现有资料没有明确说明“失业登记不会影响求职”。
   - 如要加入评测，需要补充失业登记政策解读、公共就业服务问答或官方 FAQ。

4. `登记失业人员能享受哪些服务？`
   - 现有资料能部分说明《就业创业证》可用于公共就业服务和就业扶持政策，但缺少完整服务清单。
   - 建议补充公共就业服务事项清单或登记失业人员服务政策文件。

5. 创业担保贷款细则类问题
   - 当前已入库资料可支撑个人最高 30 万元、小微企业最高 400 万元、贷款期限、50% 贴息、部分申请对象、甘人社通〔2024〕299 号等。
   - 以下细则证据不完整：累计申请次数不超过 3 次、展期条件、担保方式、10 万元以下免反担保、再次申请是否需要失业登记证明、农户种养殖无营业执照如何申请。
   - 建议补充《甘肃省创业担保贷款实施办法》全文或当地创业担保贷款政策问答。

6. 高校毕业生就业登记
   - 现有资料对“就业登记对象”和“失业登记中的离校未就业高校毕业生”有依据。
   - 缺少“高校毕业生可办理就业登记、申领就业创业证、享受公共就业创业服务”的专项表述。
